# TCIM新五表V0.2.1系统校验报告

校验日期：2026-08-30

适用范围：本机研究比较版、`SIMULATION_ACTIVE`

校验原则：保持五表的职责、字段语义、Dialogue Agent主导权和低延时目标不变，只修复确定性的映射、编译和运行路由缺陷。

## 一、结论

V0.2.1五表的数据结构、跨表引用、认识状态、证据路径、画像归因和运行时来源已经闭合。五个活动工作簿共487条记录，编译后形成10题运行卡、55条证据政策、68条对话政策、48条综合/记忆政策和14条硬边界。第三轮系统审计结果为：错误0、警告0。

本轮没有改变五表分工，也没有增加固定问句、必问路线或自动评分权。修订集中在“原有信息怎样被正确传递和使用”。

## 二、本轮发现并修复的隐藏问题

1. 情境叙事被重复编入情境事实。
   - 原因：编译器只按`epistemic_status=SCENARIO_FACT`分组，导致`SCENARIO_NARRATIVE`同时进入叙事字段和事实数组。
   - 影响：有限的事实输入名额可能被重复叙事占用，真正的情境事实被挤出模型输入。
   - 修复：情境事实现在必须同时满足`item_type=SCENARIO_FACT`和`epistemic_status=SCENARIO_FACT`。

2. 表2路径父级与表3能力引用只检查“有重合”，没有检查“完全一致”。
   - 原因：旧门禁只要一项能力重合就判定通过，无法发现多余、遗漏或错位能力。
   - 影响：证据可能被解释到所绑定专业路径之外；其中Q07-T3-004和Q10-T3-005的主要画像能力不属于原路径父级。
   - 修复：校正Q07—Q10共10条跨表能力映射；主要画像能力必须属于路径父级；`capability_refs`必须与绑定路径父级集合完全一致。

3. C09“同伴互动、规则与共同体协调”没有任何主要画像证据入口。
   - 原因：Q10-T3-005的证据内容、路径和主要画像能力发生错位。
   - 影响：无论教师怎样回答，C09都不可能进入画像。
   - 修复：Q10-T3-005回到“规则试行—反馈—修订—教师渐退”的证据命题，主要归入C09；十题现在覆盖C01—C12全部12个画像维度。

4. 四个专业视角名额可能被同一能力的多条路径重复占用。
   - 原因：表2以“路径”为行，模型输入直接截取前四行，没有先按能力概念去重。
   - 影响：名义上提供四个视角，实际可能只有一到两个不同能力，削弱Ontology扩大专业视野的作用。
   - 修复：先按`capabilityId`聚合路径，再选择四个不同能力视角；路径变体保留在各视角的`pathOptions`中。

5. 编译边界可能进入Dialogue Agent提示。
   - 原因：非硬边界政策都被当作可选对话建议，`COMPILATION_BOUNDARY`未单独排除。
   - 影响：只用于Fixture和编译校验的规则可能占用模型提示并干扰问话。
   - 修复：前台只接收`AFFORDANCE`、`MONITOR`和`HARD_BOUNDARY`；编译边界保留在运行卡审计层，不进入模型提示。

6. “作答是否改动”的含义过窄。
   - 原因：只比较第一名是否变化，忽略第二至第四位的真实调整。
   - 影响：教师修改了排序但首位不变时，系统错误记录为“未改动”。
   - 修复：比较第一次与最终的完整顺序，但仍只向模型传递一个布尔值，不泄露完整排序或得分。

7. L0—L3锚点以字符串包裹JSON传入模型。
   - 影响：增加解析负担和转义字符，可能降低证据判断稳定性。
   - 修复：编译时转为结构化对象；字段含义和四级标准不变。

## 三、确认属于合理设计而非缺陷的项目

- 表2部分专业路径没有对应正式证据命题：允许。Ontology负责扩大理解空间，不要求每条路径都成为评分或画像入口。
- 表3的RO0—RO4来源政策不被表4作为提问目标：允许。它们用于判断回答来源，不是专业谈话主题。
- 表5只引用每题部分证据命题用于综合门槛：允许。未被综合策略点名的证据仍可进入Canonical Evidence和有边界的画像候选。
- 未谈到某个能力不等于能力低：继续保留，画像中必须显示“未观察到”而非负面结论。

## 四、仍需保留的工程边界

1. 当前比较版已经编译并保存表5，但完整的、可配置的`Synthesis/Memory Policy Executor`尚未独立实现。现有画像、纠正、来源隔离和时间收尾主要由确定性程序执行，结果与表5核心原则一致，但还不能证明表5每条综合与长期记忆政策都被逐条执行。这是下一阶段P1工程项，不是本轮五表数据阻断项。
2. 五表仍是AI模拟研究团队复核候选，不等于真人专家效度批准。真实教师试用、专家盲评、公平性和跨模型稳定性仍由TEVV决定。
3. 不同模型的问话质量、延时和遵循度仍需用同一Fixture集比较；数据校验通过不能替代模型效果验证。

# 整体访谈模块

独立入口：`/gsyg-web/overall/`。它不会改变原测验和逐题访谈。

## 管理员流程

1. 先登录现有“研究数据工作台”。
2. 打开 `/gsyg-web/overall/#admin`。
3. 同时选择“答题结果”与“答题过程”两份 `.xlsx` 文件并导入。

结果表须包含姓名、答题时长和题号列。过程表既兼容标准12列表头，也兼容旧合集导出中没有表头、数据直接从第一行开始的格式。新导入的数据成为当前批次；旧批次和已经产生的访谈不会删除。

## 教师流程

教师只输入测验时填写的姓名。服务器在当前批次中精确匹配姓名，并用签名会话绑定唯一资料。找不到姓名或出现同名时不会展示候选名单，也不会进入访谈。

## 数据边界

- 浏览器不接触其他教师资料。
- 最终排序来自结果表；过程表只用于还原修改次数、排序路径和作答用时。
- 访谈按整场约12分钟运行，不设置逐题最低轮数。
- 云端集合：`gsyg_overall_datasets`、`gsyg_overall_teacher_inputs`、`gsyg_overall_sessions`。
